# uploads/

Coloca acá las fotos reales para las mini interfaces de la sección
"Un sistema visual distinto para cada tipo de negocio" en `index.html`.

El código ya está preparado para leerlas — solo hace falta agregar los
archivos con estos nombres exactos:

**Restaurantes**
- `restaurante-ceviche.jpg`
- `restaurante-risotto.jpg`
- `restaurante-tiradito.jpg` (también se usa como foto de portada del mockup)

**Clínicas**
- `clinica-doctora-1.jpg`
- `clinica-doctor-2.jpg`

**Barberías**
- `barberia-hero.jpg` (foto de portada del local o de un corte)

**Marcas personales**
- `marca-portrait.jpg` (retrato o foto de perfil)

**Tiendas**
- `tienda-tenis.jpg`
- `tienda-mochila.jpg`

Recomendado: fotos bien iluminadas, recortables a cuadrado cuando el
mockup lo pida. Mientras un archivo no exista, esa tarjeta muestra
automáticamente un degradado de la marca en su lugar — no se rompe nada
si tardás en subir las fotos.
